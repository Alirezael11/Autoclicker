# Auto Clicker (پژوهشی)

اپ اندرویدی که با سرویس دسترس‌پذیری (Accessibility Service)، دکمه‌ای با متن یا شناسه‌ی مشخص را در اپ هدف پیدا و به‌صورت خودکار کلیک می‌کند.

## امکانات
- دکمه‌ی شروع/توقف و نمایش وضعیت سرویس
- اسلایدر سرعت ۱ تا ۱۰ (تأخیر واکنش ۵۰۰ تا ۵۰ میلی‌ثانیه)
- تعیین هدف با متن دکمه، شناسه‌ی View، و محدود کردن به یک اپ خاص (نام بسته)
- فیلتر «فقط وقتی این متن هست» و «اگر این متن بود کلیک نکن»
- شمارنده‌ی کلیک و آخرین رویداد
- جلوگیری از هنگ کردن: رویدادهای پشت‌سرهم ادغام می‌شوند و بین دو کلیک فاصله‌ی حداقلی هست

## ساخت APK — روش ۱: GitHub (بدون نیاز به کامپیوتر قوی)
1. یک مخزن (repository) جدید در github.com بسازید.
2. همه‌ی فایل‌های این پوشه را آپلود کنید (پوشه‌ی مخفی `.github` هم باید آپلود شود).
   - اگر آپلود پوشه‌ی `.github` ممکن نشد: در مخزن، **Add file → Create new file** بزنید، نام فایل را `.github/workflows/build-apk.yml` بگذارید و محتوای همین فایل را در آن کپی کنید.
3. به تب **Actions** بروید؛ ساخت خودکار شروع می‌شود (حدود ۵ دقیقه).
4. روی اجرای سبز‌رنگ بزنید و از بخش **Artifacts** فایل `AutoClicker-apk` را دانلود کنید. داخل zip، فایل `app-debug.apk` است.

## ساخت APK — روش ۲: Android Studio
1. پوشه را در Android Studio باز کنید (File → Open).
2. صبر کنید Gradle همگام‌سازی شود.
3. **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
4. فایل در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

## نصب و راه‌اندازی روی گوشی
1. APK را نصب کنید (نصب از منابع ناشناس را اجازه دهید).
2. اپ را باز کنید و «باز کردن تنظیمات دسترس‌پذیری» را بزنید، سپس Auto Clicker را روشن کنید.
3. **اندروید ۱۳ به بعد:** اگر گزینه خاکستری بود، در «اطلاعات برنامه» از منوی ⋮ گزینه‌ی **Allow restricted settings** را بزنید و دوباره امتحان کنید.
4. متن دکمه و نام بسته‌ی اپ هدف را وارد کنید و «شروع» را بزنید.

## پیدا کردن شناسه‌ی View
با فعال بودن `flagReportViewIds` می‌توانید از ابزارهایی مثل **Layout Inspector** در Android Studio یا `uiautomator dump` شناسه را پیدا کنید. کافی است فقط بخش آخر (مثلاً `refresh_button`) را وارد کنید؛ اپ آن را با نام بسته کامل می‌کند.

## ساختار کد
- `MyAccessibilityService.kt` — سرویس اصلی: دریافت رویدادها، فیلترها، پیدا کردن و کلیک
- `AutomationState.kt` — تنظیمات و وضعیت مشترک (ذخیره در SharedPreferences)
- `MainActivity.kt` — صفحه‌ی اصلی با Jetpack Compose
- `res/xml/accessibility_service_config.xml` — پیکربندی سرویس
